1. **[blocking]** `Remanence/RecordView.swift:493` — Shelf stays enabled while `isFinishing` is true, and it calls `close()` (`Remanence/RecordModel.swift:116`), which does not refuse during that wait. `close()` runs on leave (`Remanence/RecordView.swift:66`), so the sidebar and the collection link (`Remanence/RecordView.swift:124`) do the same thing. `close()` sets `target = nil`, drops `recordingTapeID`, and sets `stage` back to setup while `finish()` is still inside `finishCapture`. `startRecording()` (`Remanence/RecordModel.swift:275`) does not check `isFinishing`. A new take started in that window stores its own `target`, then the old `finish()` clears `target` and calls `resumePipeline()` (`Remanence/RecordModel.swift:343`). Stopping that new take finds no `target`, so `finishCapture` never runs and the pipeline is resumed while the input is recording. New Tape is disabled for this race. Shelf is not.
